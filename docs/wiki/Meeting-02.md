# Issues Discussed & Solutions Agreed

- **Project concept:** The project will investigate a tower defence simulation game with dynamic tower and item upgrades, supported by telemetry feedback to analyse feature adoption.

- **Technology stack:** Flame will provide the game loop, Deferred Components will support asset delivery, Shorebird will support Dart logic patches, and `dart:ffi` will provide native interoperability where required.

- **MVP gameplay:** The initial game should support buying, selling, and placing towers, an enemy wave lifecycle, and gold rewards.

- **Incubator mechanic:** An incubator building will merge two towers according to a genetic code specified in JSON.

- **Evaluation data:** Telemetry logging and a leaderboard will be used to examine optimal tower combinations.

- **Potential extensions:** Later work could explore telemetry-driven Shorebird patches, such as changing fire resistance, and dynamic tower certificates or encryption.
