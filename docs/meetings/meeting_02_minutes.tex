\section{Issues Discussed \& Solutions Agreed}

\begin{itemize}[leftmargin=*]
    \item \textbf{Project concept:} The project will investigate a tower defence simulation game with dynamic tower and item upgrades, supported by telemetry feedback to analyse feature adoption.
    \item \textbf{Technology stack:} Flame will provide the game loop, Deferred Components will support asset delivery, Shorebird will support Dart logic patches, and \texttt{dart:ffi} will provide native interoperability where required.
    \item \textbf{MVP gameplay:} The initial game should support buying, selling, and placing towers, an enemy wave lifecycle, and gold rewards.
    \item \textbf{Incubator mechanic:} An incubator building will merge two towers according to a genetic code specified in JSON.
    \item \textbf{Evaluation data:} Telemetry logging and a leaderboard will be used to examine optimal tower combinations.
    \item \textbf{Potential extensions:} Later work could explore telemetry-driven Shorebird patches, such as changing fire resistance, and dynamic tower certificates or encryption.
\end{itemize}
