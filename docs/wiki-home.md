## Where these pages come from

Every page in this wiki is generated from the source files in `docs/` in the
main repository. **Do not edit pages here or in the local wiki clone**,
because they are overwritten on every publish. Edit the file in `docs/`, then
run:

```bash
make publish-wiki
```
